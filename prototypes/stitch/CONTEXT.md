# Prototype Context

## Purpose

Reviewable HTML/CSS concepts used to validate visual direction and interaction before production implementation.

## Architecture

- `index.html`: Central catalog linking to all generated prototype screens.
- `menubar.html` & `menubar.png`: Menu bar popover status window prototype.
- `add_remote.html` & `add_remote.png`: Add cloud storage wizard dialog sheet prototype.
- `settings.html` & `settings.png`: Preferences and settings window prototype.

## Current State

Interactive high-fidelity prototypes generated via Google Stitch in **macOS Tahoe** design language (frosted glass, vibrancy, dark mode).

## Dependencies

- `roadmap/specs/004_SPEC_menubar_ui.md`: Specification for MenuBarExtra & Native Settings UI.
